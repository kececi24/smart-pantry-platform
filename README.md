# Recipe and Smart Pantry Platform

A platform where users maintain a digital inventory of food available at home, including quantities and expiration dates. The system can associate pantry ingredients with recipes, help users find suitable recipes, create shopping lists, and track food consumption.

The planned application uses Python and Flask with server-rendered Jinja templates, MySQL/InnoDB, handwritten parameterized SQL through `mysqlclient`, Bulma CSS components, project-specific CSS, and small JavaScript/fetch enhancements.
